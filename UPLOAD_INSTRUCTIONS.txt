M&C：星痕公會 V9.3 — 編隊 + 復活修正版

先做 1 次 Supabase：
1. Supabase > SQL Editor > New query
2. 貼上 V9_3_PARTY_MIGRATION.sql
3. Run
4. 看到 Success 即可

然後覆蓋 GitHub 根目錄：
- index.html
- v9.js
- v9.css
- sw.js

圖片資料夾不用重傳。

本版修正：
- 可手動選擇最多 5 名冒險家上場。
- 編隊保存在 Supabase，M/C 兩邊共用。
- 可隨時恢復「戰力最高五人」自動編隊。
- 單一冒險家倒地後約 3 秒自動復活。
- 全隊死亡立即滿血復活。
- 全滅後不退關；同一區、同一關重新從 0/50 小怪開始。
- 修正 V9.2 雖然有 revive function，但 battleTick 根本沒有呼叫它的問題。

目前抽卡程式：
角色神話每抽 0.6%；角色十連至少一隻神話 = 5.84%。
裝備神話每抽 0.7%；裝備十連至少一件神話 = 6.78%。
